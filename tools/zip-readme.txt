OzMaker {version}
게임·프로그램 화면을 움짤(GIF · WebP · AVIF)과 MP4로 만드는 Windows 녹화 도구

■ 실행
  OzMaker.exe를 실행하면 됩니다. 설치는 없습니다.
  처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요.
  코드 서명이 없는 프로그램이라 뜨는 창입니다.
  Windows 11에서 스마트 앱 컨트롤이 켜져 있으면 실행이 막힙니다
  (Windows 보안 > 앱 및 브라우저 컨트롤).

■ 필요한 것
  64비트 Windows 10 / 11
  Windows N 에디션에서 MP4를 쓰려면 미디어 기능 팩이 필요합니다.

■ 포터블로 쓰기
  OzMaker.exe 옆에 빈 settings.ini 파일을 만들면 설정이 그 파일에 저장됩니다.
  이 PC의 시작 프로그램에는 등록하지 않습니다.

■ 지우기
  트레이 아이콘에서 종료한 뒤 OzMaker.exe와 %APPDATA%\OzMaker 폴더를 지웁니다.

■ English
  OzMaker shows English when Windows is not in Korean.
  To change it: Settings (the gear at the top right) › General › Language.
